# Payvora Mobile (Expo SDK 57)

A state-of-the-art Expo SDK 57 and React Native finance application with a custom geometric identity, Manrope typography, luxury fintech styling, and connected demo workflows.

## Included flows

- Animated splash and three-step onboarding
- Sign in, sign up, password recovery and OTP verification
- Luxury Home dashboard with smart EMV chip balance card and quick actions
- Send money with recipient, amount, review and success steps
- Request money and add money forms
- Searchable transaction history and transaction details
- Virtual/physical cards, freeze controls and add-card flow
- Bill payments for utilities, mobile, internet and subscriptions
- Beneficiaries and quick contacts
- Profile, personal details, notifications, security and support
- Local persistence for session, balance, cards and transactions
- Custom scalable Payvora geometric logo and wordmark
- Skeleton dashboard and animated secure-processing loaders
- Haptic interactions and motion-enabled cards/actions
- Realistic Visa, Mastercard and merchant brand marks
- QR scan/pay and personal QR experience
- Currency exchange calculator and confirmation
- Spending analytics with animated category charts
- Linked bank accounts and beneficiary management

## Run locally

1. Install Node.js 20 or later.
2. From this folder, run `npm install`.
3. Run `npm start`.
4. Scan the QR code with Expo Go, or press `a`, `i`, or `w` for Android, iOS, or web.

The app is a frontend demo. Payments are simulated locally and no real financial transaction is made.
